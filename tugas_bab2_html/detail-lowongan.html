Deskripsi Pekerjaan

Ringkasan: Mengembangkan sistem web enterprise berbasis NestJS REST API, Prisma ORM, dan React Frontend yang berkinerja tinggi serta modular.

Rincian Tugas & Tanggung Jawab:

  • Bertanggung jawab penuh dalam merancang arsitektur API microservices yang aman, teruji, dan terdokumentasi rapi.
  • Melakukan integrasi third-party services seperti payment gateway, notification service, dan cloud storage.
  • Membangun antarmuka web modern, responsif, dan ramah aksesibilitas menggunakan React, TypeScript, dan Tailwind CSS.
  • Melakukan optimasi performa database PostgreSQL / MySQL, query caching Redis, serta indeks data.
  • Bekerja sama dalam sprint Agile / Scrum dan berpartisipasi aktif dalam sesi code review tim.

Persyaratan Teknis & Kualifikasi

Persyaratan Keahlian Teknis (Syarat):

  1. Pengalaman kerja minimal 2 tahun dalam pengembangan web modern menggunakan Node.js (NestJS / Express) dan React.js / Next.js.
  2. Mahir dalam bahasa pemrograman TypeScript dan standar JavaScript modern (ES6+).
  3. Memahami perancangan RESTful API, ORM (Prisma / TypeORM), dan manajemen basis data relasional (PostgreSQL / MySQL).
  4. Familiar dengan Git version control, GitHub workflow, dan automated CI/CD pipeline.
  5. Memiliki portofolio proyek web aktif atau repositori GitHub publik yang dapat ditinjau.

Kualifikasi Latar Belakang:

  • Pendidikan minimal S1 Teknik Informatika, Sistem Informasi, Ilmu Komputer, atau bidang sains teknologi terkait.
  • Memiliki integritas tinggi, proaktif, dan kemampuan komunikasi verbal & tertulis yang baik.

Fasilitas, Tunjangan & Keuntungan (Benefit)

  • Gaji pokok kompetitif sesuai kualifikasi dan pengalaman kerja.
  • BPJS Ketenagakerjaan dan BPJS Kesehatan resmi pemerintah.
  • Asuransi kesehatan rawat inap dan rawat jalan swasta.
  • Fasilitas laptop kerja high-end dan tunjangan perlengkapan developer.
  • Tunjangan Hari Raya (THR) penuh dan Bonus Kinerja Tahunan.
  • Budget tahunan untuk pelatihan, sertifikasi IT internasional, dan buku teknis.
